# Nebius × NVIDIA submission package

## Target category
**Best Apps and Agents**. Physical AI is not targeted; web-only is valid under the supplied requirements. Verify official rules/deadline independently.

## Mandatory elements from supplied brief
- Working app powered by NVIDIA open-source model through Nebius Token Factory or AI Cloud.
- Working demo URL (except special Physical AI exception, not applicable here).
- Public code repository (GitHub/GitLab/Bitbucket) with top-level open-source license (MIT/Apache-2.0/MPL-2.0).
- README with setup and execution instructions.
- Public YouTube video <= 3 minutes demonstrating the system and Nebius/NVIDIA usage.
- Project description, category, tool/model usage, Nebius feedback.
- Explain substantial updates if preexisting code was used.
- City event selection only if applicable; do not invent participation.

## Judging criteria and proof
**Technical**: show actual Nebius inference request/model, LangGraph tool trace, deterministic graph calculations, durable job handling.
**Design**: intuitive citizen web reporting and accessible coordinator workflow.
**Impact**: real source records, specific user journey, qualified alternative and measurable coordinator time savings.
**Idea**: cross-sector human access dependency graph, same workflow for citizen and autonomous events.
**Tavily optional prize**: use for discovery of public notices, then verify primary source.
